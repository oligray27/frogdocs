# Live Service Games

Some games never really end: MMOs, competitive shooters, Fortnite, Destiny, daily puzzle games. A start and end date doesn't fit them, so FrogLog tracks them as **live service games**, with your play logged as a series of [sessions](/library/sessions).

Live service games have their own **Live Service** tab on the Games page.

## Adding a live service game

Add the game from Search as usual, and tick **Live Service** in the Add New Game form. The button at the bottom changes to **Add to Live Service**.

To move a game you've already added, open its edit form and click **Move to Live Service**. To move several at once, or to move one back, use **Transfer** in the toolbar. See [Your Library](/library).

## What's different

| | Regular game | Live service game |
|---|---|---|
| Dates | Start and end date | None. The details card shows your session count and when you last played. |
| Hours | One total, or the sum of its sessions | Always the sum of its sessions |
| Status | Not Started, In Progress, Completed, DNF or Dormant | **Active**, or **Dormant** if you've stopped playing for now |
| Table columns | Hours, rating, status, last played | Hours, sessions, rating, last played |

Set a live service game to **Dormant** in its edit form when you drift away from it, and back to **Active** when you return.

Everything else works the same: ratings, reviews, screenshots, trophies, Quick Session and privacy.

## One library instead of two tabs

If you'd rather not split your library, turn on **Profile > Settings > Library Defaults > Unify Games & Live Service**. Then:

- The Games page shows one combined table, with no tabs.
- Live service games show the status **Live Service** (green while active, grey when dormant).
- In the add and edit forms, the **Live Service** checkbox becomes **No End Date**, which is available once **Enable Session Tracking** is ticked. Its status options are **In Progress** and **Dormant**.

You can also choose which tab the Games page opens on with **Default Main Table View**, in the same settings section.
