## Not covered

These parts of the API exist for the FrogLog website and LilyPad, and aren't documented for general use. They may change without notice:

- Logging in and signing up
- Linking, importing and tracking settings for Steam, PlayStation, Xbox and Switch
- Individual settings (theme, layout and so on)
- Uploading photos, banners, backgrounds and theme music
