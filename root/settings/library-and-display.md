# Library & Display

These two settings sections control how your library opens and how FrogLog looks on your screen.

## Library Defaults

### Default sorts

| Setting | What it does |
|---|---|
| **Default Games Sort** | How the Games table is sorted when it opens: Start Date, End Date, Last Played, Title, Hours, Rating or Status, with **Desc** or **Asc** |
| **Default Live Service Sort** | The same for the Live Service table: Last Played, Title, Hours, Sessions or Rating |
| **Default Merged Sort** | The same for the combined table, when **Unify Games & Live Service** is on |

The Games and Live Service sorts are greyed out while Unify is on, and the merged sort is greyed out while it's off.

### Other library settings

| Setting | Options | What it does |
|---|---|---|
| **Default Main Table View** | Games / Live Service | Which tab the Games page opens on |
| **Default Table Layout** | Rows / Grid | Whether your library opens as a table or a grid of covers |
| **Unify Games & Live Service** | Separate / Unified | Combines your games and live service games into one library. See [Live Service Games](/library/live-service-games). |
| **Group Replays in Table** | Grouped / Flat | Tucks replays under the original game. See [Replays and DNF](/library/replays-and-dnf). |
| **Mobile Status Dot** | Shown / Hidden | The coloured status dot on each row on a phone |
| **Confirm Steam Links** | Confirm / Auto-link | Whether adding a game asks before linking it to Steam. See [Matching Games](/platforms/matching-games). |
| **Playing Badge** | Date / Days Ago | Whether a game you're playing shows the date you started or how many days ago that was |

## Display & Layout

| Setting | Options | What it does |
|---|---|---|
| **Default Details Card Image Size** | Collapsed / Expanded | Whether the details card's artwork starts large or small |
| **Widescreen Layout** | Enabled / Disabled | On large screens, uses a wider two-column layout with your library beside the details card |
| **Default Rating Mode** | Stars (1–5) / % (0–100) | How ratings are shown and entered everywhere |
| **Pin Navbar** | Auto-hide / Pinned | Keeps the top bar on screen instead of sliding it away as you scroll |
| **Pin Bottom Bar** | Auto-hide / Pinned | The same for the bottom bar on a phone |
| **Show Steam Title Image** | Show / Hide | Shows a game's logo over its artwork on the details card, in place of its name |

To choose which pages are in the bottom bar on a phone, see **Bottom Navigation (Mobile)** in [Profile](/settings/profile).
